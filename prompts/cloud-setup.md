# Cloud setup prompt for Grok Bot

**English** | [简体中文](cloud-setup.zh-CN.md)

`[LOCAL]`, the user's local computer (Mac): the last installer step prints this prompt with the team name, Bot address name, Mac home directory, and repository URL filled in. The user sends it with the invite to the Bot in `[GROK-UI]`, the Grok Bot interface. Reprint it on `[LOCAL]` with `./install.sh --cloud-prompt --lang en`. The template below has unfilled placeholders; keep their names unchanged in translations.

```
You are Grok Bot. Execution location labels: [LOCAL] = the user's local computer (Mac); [BOT-CLOUD] = your Bot cloud computer (machine name cloud); [GROK-UI] = the Grok Bot interface opened by the user. Labels are not part of commands.
Join my Reason Network team on [BOT-CLOUD], using the machine name cloud. Run all shell commands below on [BOT-CLOUD], not on [LOCAL]. Keep all cloud files under the persistent directory /workspace/agent-mesh/ and do not leave any process running in the background. Reply to me in my preferred language.
1. [BOT-CLOUD] First check for Linux x86_64 or ARM64, Bash, Git, Python 3.9+ with ssl and sqlite3, curl, tar, sha256sum, writable persistent /workspace storage, HTTPS access to GitHub, and iroh connectivity. Prepare missing dependencies for the cloud system first and tell the user if permissions are needed. Once ready, run git clone <repo-url> /workspace/agent-mesh. If the directory exists, confirm it is the same public distribution repository with no uncommitted code changes before running git -C /workspace/agent-mesh pull --ff-only; stop and explain if it is not a repository, has a different source, or contains changes. Do not overwrite files. The default HTTPS URL needs no GitHub account or SSH key; if a custom SSH URL lacks credentials, use the same public repository's HTTPS URL. Do not request the user's SSH private key.
2. [BOT-CLOUD] Run /workspace/agent-mesh/box/rn-cloud-setup.sh '<invite-link>' <team-name> <relay-name>. The script downloads the same reason-network version to box/bin, joins with box/state as the engine directory, and disables auto_update, lan, and tray. Use the invite supplied above this prompt. Then run cat /workspace/agent-mesh/box/relay. Continue if it prints <relay-name>, or if the file does not exist and <relay-name> is bot. Otherwise stop and tell the user that the cloud clone is older than the Mac's installer.
3. [LOCAL] → [BOT-CLOUD] Use CopyToBox to copy the key: source <mac-home>/.config/agent-relay/outbound.key on the user's local computer, destination /workspace/agent-mesh/box/outbound.key on your Bot cloud computer. Use an absolute source path; the user approves the copy in [GROK-UI]. Then run chmod 600 on the destination on [BOT-CLOUD]. The source path belongs to the Mac; do not try to read it directly on the cloud computer. Keep the key contents out of chat.
4. [BOT-CLOUD] Run /workspace/agent-mesh/box/rn-cloud.sh who. You should see the user's sessions on [LOCAL]. After checking, tell me that the cloud has joined. This confirms cloud team membership; messaging in both directions still needs the runbook's tests.
```
